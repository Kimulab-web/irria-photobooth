# Irria Photobooth

Site vitrine SEO (Astro) pour Irria Photobooth — location de photobooth
artisanal en bois au Pays Basque et dans les Landes.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Déploiement

Voir [README-DEPLOY.md](./README-DEPLOY.md) pour la configuration DNS
(o2switch), les variables d'environnement Vercel et la config Resend.
